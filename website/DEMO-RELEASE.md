ConFellow is an experimental conference companion: capture spoken or typed notes, explore topic spaces, and star scheduled talks in a blue phosphor radar interface.

Download **confellow-demo.apk** below on an **ARM64 Android phone running Android 7.0 (API 24) or later**. Open the file and allow your browser or file manager to install unknown apps if prompted. The offline Whisper model is bundled, so use Wi-Fi for the download and allow extra storage for its first-run copy. English transcription is the current default. Device performance varies.

This is a **hackathon demo**, signed with a development key, outside the Play Store. Discovery runs in explicitly labeled demo mode, not live attendee matching. Each clean CI build may use a different development signing key. Android may require uninstalling an earlier demo before installing this one; uninstalling clears its local data and secure credentials. Do not uninstall an app with recordings you still need.

The app's Android launcher name in this branch is `conversation_garden`; its in-app name is ConFellow.

Microphone audio is processed on the phone. Private realtime transcript saving requires separate opt-in and an internet connection. Review/Undo for note submission does not remove private transcript uploads. Ask before recording other people.

The adjacent **confellow-demo.apk.sha256** file contains the APK's SHA-256 checksum. These are demo builds, not production-signed releases; no production signing credentials are required or included.
