A little setup. Then you’re in.

  1. Download the APK.

    Open this page on your Android phone and download the demo from GitHub Releases. Wi-Fi is a good idea: the offline speech model is bundled.

  2. Allow this installation.

    Open the downloaded file. If Android prompts you, allow your browser or file manager to install unknown apps, then install ConFellow. You can turn that permission off afterward.

  3. Start with your own thought.

    Open the app and speak or type a note. Grant microphone permission to use voice capture. Ask before recording anyone else.

Made for a hackathon. Still an experiment.

This is a demo-signed APK, distributed outside the Play Store. Discovery uses demo data. Performance varies by phone; an iOS download is not available.

A FEW THINGS TO KNOW

Before you tune in.

Does everything work offline?

Speech transcription runs on device with the bundled model. The bundled schedule and demo discovery can be explored locally. Cloud transcript saving and backend searches need an internet connection.

Is the radar a map of people near me?

No. Distance on the radar represents topic relevance, not physical location. The hackathon build defaults to labeled demo discovery rather than live attendee matching.

Why isn’t this on the Play Store?

This is a hackathon prototype shared directly as an APK. GitHub Releases holds the downloadable build, release notes, and a SHA-256 checksum. Future demo builds may require uninstalling an earlier build if their signing key changes; uninstalling removes local app data.

Can I see how it works?

Yes. ConFellow is open source. Explore the Flutter app and backend on GitHub, including the transcript API and privacy behavior.
